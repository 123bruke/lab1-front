# AFRO AI Context Manager








A simple landing page project built with Next.js and Tailwind CSS.

This repository contains a modern SaaS-style homepage for AFRO AI, focused on presenting AI agent workflows, product features, pricing, testimonials, and a clear call-to-action flow.





## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Radix UI
- Lucide React

## Features

- Modern hero section with product branding
- Multiple feature blocks showcasing AI workflows
- Pricing and testimonial sections
- FAQ and call-to-action footer
- Responsive design for different screen sizes

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the app:

```bash
npm run dev
```

3. Open in browser:

```bash
http://localhost:3000
```

## Build for production

```bash
npm run build
```

## Start production build

```bash
npm run start
```

## Notes

This project is a front-end landing page and can be used as a starter for an AI product website or SaaS marketing page.
